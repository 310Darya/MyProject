# Каталог домашней библиотеки (OOP Project)

Java-приложение для управления домашней библиотекой. Проект демонстрирует использование принципов объектно-ориентированного программирования: инкапсуляции, композиции, наследования и полиморфизма.

## Требования к запуску
- Java 21 (используются новые возможности языка: record, var, switch expressions)
- Maven (система сборки проекта)
- JUnit 5 (фреймворк для тестирования)

## Архитектура модели данных

### Основные классы (Пакет com.library.model)
- Book — сущность книги. Уникальным идентификатором является ISBN. Для него переопределены методы equals() и hashCode(), чтобы корректно сравнивать книги именно по номеру, а не по ссылке.
- Author — автор книги. Реализован как record (неизменяемый объект), так как данные автора не меняются после создания.
- BookCopy — конкретный физический экземпляр книги на полке. Содержит ссылку на Book, текущее состояние (CopyState) и место хранения.
- Genre — перечисление (enum) жанров книг. Содержит поля с описанием жанра.
- CopyState — перечисление состояний экземпляра: AVAILABLE (доступен), LOANED (выдан), LOST (утерян), REPAIR (в ремонте).

### Композиция места хранения
Место хранения реализовано через строгую композицию объектов:
Room (Комната) -> Shelf (Шкаф) -> ShelfRow (Полка) -> StorageLocation (Точка хранения).
Это позволяет гибко менять структуру библиотеки и точно знать, где лежит каждая книга.

### Обработка ошибок (Исключения)
Вместо возврата кодов ошибок используются собственные исключения:
- LibraryException — базовый класс для всех ошибок библиотеки.
- AlreadyLoanedException — выбрасывается, если пытаются выдать книгу, которая уже у читателя.
- NotLoanedException — выбрасывается, если пытаются вернуть книгу, которая не была выдана.

## Реализованный функционал

### Базовый уровень 
Интерфейс Searchable реализует основные операции поиска:
- searchByAuthor(Author) — поиск всех экземпляров конкретного автора.
- searchByTitle(String) — поиск по частичному совпадению названия (регистр не важен).
- searchByGenre(Genre) — фильтрация книг по жанру.
- whereIs(String id) — возвращает полный текстовый адрес книги (Комната, Шкаф, Полка).
- loanCopy / returnCopy — операции выдачи и возврата с проверкой статусов.

### Повышенный уровень
- moveShelfContents — массовое перемещение книг при перестановке мебели.
- getHistoryByBook — история всех выдач конкретной книги по ISBN.
- getShelfOccupancyReport — статистика заполненности полок (использует Stream API).
- getGenreDistribution — распределение фонда по жанрам.

## Тестирование 
Проект покрыт модульными тестами (15 сценариев в классе LibraryCatalogTest):
- Проверка корректности поиска (включая граничные случаи, например, пустой каталог).
- Проверка бизнес-логики выдачи и возврата.
- Проверка выброса исключений (assertThrows) при некорректных действиях.
- Проверка контракта равенства объектов (equals/hashCode) для класса Book.
